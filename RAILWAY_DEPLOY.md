## 🔧 Настройка в Railway

### 1. Переменные окружения

В панели Railway добавьте следующие переменные:

```env
# Основные настройки
BOT_TOKEN=ваш_токен_бота
ADMIN_ID=ваш_telegram_id
REMINDER_HOURS=2

# Web App URL (замените на ваш домен Railway)
WEBAPP_URL=https://ваш-проект.railway.app

# База данных (автоматически создается Railway)
DATABASE_URL=postgresql://... (автоматически)

# Окружение
NODE_ENV=production
```

### 2. Настройка сервисов

Railway автоматически определит два сервиса:
- **Основной сервис** (index.js) - порт 3000
- **Web App сервис** (webapp/server.js) - порт 3001

### 3. Настройка домена

1. В Railway Dashboard перейдите в настройки проекта
2. Добавьте кастомный домен для Web App
3. Обновите `WEBAPP_URL` с новым доменом

### 4. Настройка бота в Telegram

1. Перейдите к @BotFather
2. Выполните команду `/setmenubutton`
3. Выберите вашего бота
4. Установите URL Web App: `https://ваш-домен.railway.app`

## 🎯 Проверка работы

### 1. Проверка бота
- Отправьте `/start` боту
- Должно появиться меню с кнопкой "📱 Открыть приложение"

### 2. Проверка Web App
- Нажмите "📱 Открыть приложение"
- Должен открыться полноэкранный интерфейс
- Проверьте выбор даты и времени

### 3. Проверка API
- Откройте `https://ваш-домен.railway.app/api/slots`
- Должен вернуться JSON с доступными слотами

## 🐛 Устранение неполадок

### Бот не отвечает
1. Проверьте `BOT_TOKEN` в переменных окружения
2. Убедитесь, что нет конфликта с другими экземплярами
3. Проверьте логи в Railway Dashboard

### Web App не открывается
1. Проверьте `WEBAPP_URL` в переменных окружения
2. Убедитесь, что домен добавлен в настройки бота
3. Проверьте, что Web App сервис запущен

### Ошибки базы данных
1. Проверьте, что PostgreSQL добавлен в проект
2. Убедитесь, что `DATABASE_URL` установлен
3. Проверьте логи подключения к БД
