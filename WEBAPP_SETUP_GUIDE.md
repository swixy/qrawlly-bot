# 📱 Настройка Web App в Telegram

## 🔍 Проблема
Web App кнопка не появляется в Telegram боте.

## ✅ Решение

### 1. Локальное тестирование

Сначала протестируйте Web App локально:

1. **Запустите Web App сервер:**
```bash
npm run webapp
```

2. **Откройте тестовую страницу:**
```bash
start test-webapp-local.html
```

3. **Проверьте API:**
   - Откройте `http://localhost:3001/api/slots`
   - Должен вернуться JSON с доступными слотами

### 2. Настройка в Railway

#### Шаг 1: Переменные окружения
В Railway Dashboard добавьте:
```env
WEBAPP_URL=https://ваш-проект.railway.app
```

#### Шаг 2: Проверка деплоя
1. Убедитесь, что оба сервиса запущены:
   - Основной бот (порт 3000)
   - Web App сервер (порт 3001)

2. Проверьте Web App URL:
   - Откройте `https://ваш-проект.railway.app`
   - Должен загрузиться интерфейс записи

### 3. Настройка в Telegram

#### Вариант 1: Через @BotFather (рекомендуется)

1. **Откройте @BotFather в Telegram**
2. **Выполните команду:**
```
/setmenubutton
```
3. **Выберите вашего бота**
4. **Введите текст кнопки:**
```
📱 Записаться
```
5. **Введите URL Web App:**
```
https://ваш-проект.railway.app
```

#### Вариант 2: Через код (уже реализовано)

Web App кнопки уже добавлены в код:
- В главном меню (`/start`)
- В сцене записи
- В разделе "Мои записи"

### 4. Проверка работы

#### В Telegram:
1. Отправьте `/start` боту
2. Должна появиться кнопка "📱 Открыть приложение"
3. Нажмите на неё - откроется Web App

#### В Web App:
1. Должен загрузиться интерфейс с календарем
2. Выберите дату из горизонтального списка
3. Выберите время из сгруппированных периодов
4. Подтвердите запись

### 5. Устранение неполадок

#### Web App не открывается:
1. **Проверьте URL в Railway:**
   - Убедитесь, что `WEBAPP_URL` правильный
   - URL должен быть `https://ваш-проект.railway.app`

2. **Проверьте домен в настройках бота:**
   - Домен должен быть добавлен в @BotFather
   - Используйте команду `/setdomain`

3. **Проверьте SSL сертификат:**
   - Railway автоматически предоставляет SSL
   - Убедитесь, что используется HTTPS

#### Кнопка не появляется:
1. **Проверьте код бота:**
   - Убедитесь, что `WEBAPP_URL` установлен
   - Проверьте, что бот обновлен в Railway

2. **Перезапустите бота:**
   - В Railway Dashboard перезапустите сервис
   - Или отправьте `/start` боту заново

#### API не работает:
1. **Проверьте базу данных:**
   - Убедитесь, что PostgreSQL подключен
   - Проверьте, что есть слоты в базе

2. **Проверьте логи:**
   - В Railway Dashboard посмотрите логи
   - Ищите ошибки подключения к БД

### 6. Тестирование

#### Локально:
```bash
# Запуск Web App сервера
npm run webapp

# Открытие тестовой страницы
start test-webapp-local.html
```

#### В продакшене:
1. Откройте `https://ваш-проект.railway.app`
2. Проверьте API: `https://ваш-проект.railway.app/api/slots`
3. Протестируйте запись через Web App

### 7. Финальная проверка

После настройки проверьте:

- ✅ Web App открывается в Telegram
- ✅ Календарь загружается
- ✅ Время группируется по периодам
- ✅ Запись работает
- ✅ Уведомления приходят админу
