# 🚀 Настройка современного интерфейса записи

## 📱 Что добавлено

### 1. Современная сцена записи (`scenes/modern-booking.js`)
- **Горизонтальная прокрутка дат** как в Yandex/Yclients
- **Группировка времени** по периодам (Утро, День, Вечер)
- **Красивый дизайн** с эмодзи и современным UI
- **Улучшенная навигация** с кнопками назад

### 2. Web App интерфейс (`webapp/`)
- **Полноценное приложение** внутри Telegram
- **Адаптивный дизайн** для мобильных устройств
- **Темная/светлая тема** автоматически подстраивается под Telegram
- **Плавные анимации** и современный UX

## 🛠️ Установка

### 1. Установите зависимости
```bash
npm install
```

### 2. Настройте переменные окружения
Добавьте в ваш `.env` файл или переменные окружения:
```env
WEBAPP_URL=https://your-domain.com
```

### 3. Запуск

#### Вариант 1: Только бот (классический интерфейс)
```bash
npm start
```

#### Вариант 2: Бот + Web App (рекомендуется)
```bash
npm run start:all
```

#### Вариант 3: Только Web App сервер
```bash
npm run webapp
```

## 🌐 Развертывание Web App

### Для локальной разработки:
1. Запустите `npm run start:all`
2. Web App будет доступен на `http://localhost:3001`
3. Для тестирования в Telegram используйте ngrok:
```bash
ngrok http 3001
```
4. Установите полученный URL в `WEBAPP_URL`

### Для продакшена:
1. Разверните Web App на вашем хостинге (Railway, Heroku, VPS)
2. Установите URL в переменную `WEBAPP_URL`
3. Убедитесь, что домен добавлен в настройки бота в @BotFather

## 📱 Как использовать

### В чате с ботом:
1. Нажмите "✂️ Записаться на стрижку"
2. Выберите дату из горизонтального списка
3. Выберите время из сгруппированных периодов
4. Подтвердите запись

### В Web App:
1. Нажмите "📱 Открыть приложение"
2. Выберите дату и время в полноэкранном интерфейсе
3. Подтвердите запись

## 🔧 Настройка

### Изменение периодов времени
В файле `scenes/modern-booking.js` найдите функцию `groupTimeByPeriods`:
```javascript
if (hour >= 6 && hour < 12) {
  periods['Утро'].push(time);
} else if (hour >= 12 && hour < 18) {
  periods['День'].push(time);
} else {
  periods['Вечер'].push(time);
}
```

### Изменение количества дней
В функции `createHorizontalDatePicker` измените:
```javascript
for (let i = 0; i < 14; i++) { // 14 дней
```

### Настройка Web App
В файле `webapp/index.html` можно изменить:
- Цвета и стили
- Количество дней
- Периоды времени
- Анимации

## 🐛 Устранение неполадок

### Web App не открывается
1. Проверьте, что `WEBAPP_URL` установлен правильно
2. Убедитесь, что домен добавлен в настройки бота
3. Проверьте, что Web App сервер запущен

### Ошибки в консоли
1. Проверьте логи сервера
2. Убедитесь, что база данных доступна
3. Проверьте права доступа к файлам

## 📞 Поддержка

При возникновении проблем:
1. Проверьте логи в консоли
2. Убедитесь, что все зависимости установлены
3. Проверьте настройки переменных окружения
